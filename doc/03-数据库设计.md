# 数据库设计

## 1. 数据库概述

- **数据库类型**: SQLite
- **数据库文件**: `data/cleaning.db`
- **初始化**: 应用启动时自动创建表结构

## 2. 表结构

### 2.1 files - 文件主表

存储文件的基本信息和处理状态。

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `id` | INTEGER PRIMARY KEY | 自增主键 |
| `md5` | TEXT UNIQUE NOT NULL | 文件 MD5（当前版本） |
| `original_md5` | TEXT | 原始上传文件的 MD5 |
| `author` | TEXT | 作者（从文件名解析） |
| `title` | TEXT | 小说名称 |
| `file_name` | TEXT | 原始文件名 |
| `file_size` | INTEGER | 文件大小（字节） |
| `status` | TEXT | 状态：pending/processing/reviewing/completed/failed |
| `current_step` | TEXT | 当前步骤 |
| `progress` | INTEGER | 进度百分比（0-100） |
| `rules_config` | TEXT | JSON 格式的规则配置 |
| `created_at` | TIMESTAMP | 首次上传时间 |
| `updated_at` | TIMESTAMP | 最后更新时间 |
| `error_msg` | TEXT | 错误信息（失败时） |

**索引**:
- `files(md5)` UNIQUE
- `files(original_md5)`
- `files(status)`

### 2.2 versions - 版本链

维护文件的版本历史。

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `id` | INTEGER PRIMARY KEY | 自增主键 |
| `original_md5` | TEXT NOT NULL | 原始文件 MD5 |
| `version_md5` | TEXT UNIQUE NOT NULL | 当前版本 MD5 |
| `parent_md5` | TEXT | 上一个版本的 MD5（根版本为 NULL） |
| `version_type` | TEXT | 版本类型：original/intermediate/final |
| `file_path` | TEXT | 该版本文件的绝对路径 |
| `created_at` | TIMESTAMP | 创建时间 |

**索引**:
- `versions(version_md5)` UNIQUE
- `versions(original_md5)`

### 2.3 review_items - 人工审核项

存储待审核的修改建议。

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `id` | INTEGER PRIMARY KEY | 自增主键 |
| `file_md5` | TEXT NOT NULL | 关联的文件 MD5 |
| `original_text` | TEXT | 原文片段 |
| `suggested_text` | TEXT | 建议修改后的文本 |
| `modification_type` | TEXT | 修改类型 |
| `confidence` | REAL | AI 置信度（0-1） |
| `position_start` | INTEGER | 在文档中的起始字符位置 |
| `position_end` | INTEGER | 结束字符位置 |
| `line_number` | INTEGER | 原文行号 |
| `context_before` | TEXT | 上文（1 行） |
| `context_after` | TEXT | 下文（1 行） |
| `status` | TEXT | 状态：pending/accepted/rejected/edited |
| `edited_text` | TEXT | 用户编辑后的文本 |
| `created_at` | TIMESTAMP | 创建时间 |
| `resolved_at` | TIMESTAMP | 处理时间 |

**索引**:
- `review_items(file_md5, status)`

### 2.4 processing_logs - 处理日志

记录处理过程的详细日志。

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `id` | INTEGER PRIMARY KEY | 自增主键 |
| `file_md5` | TEXT NOT NULL | 关联的文件 MD5 |
| `step` | TEXT | 步骤名称 |
| `action` | TEXT | 具体操作 |
| `details` | TEXT | 详细信息（JSON 格式） |
| `status` | TEXT | 状态：running/completed/failed |
| `timestamp` | TIMESTAMP | 日志时间 |

### 2.5 chunk_repair_cache - 块修复缓存表

存储LLM修复的缓存结果，支持断点续传和幂等性。

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `id` | INTEGER PRIMARY KEY | 自增主键 |
| `file_md5` | TEXT NOT NULL | 关联的文件 MD5 |
| `chunk_id` | INTEGER NOT NULL | 块序号 |
| `chunk_hash` | TEXT NOT NULL | 块内容的哈希值 |
| `original_text` | TEXT NOT NULL | 原始文本 |
| `repaired_text` | TEXT NOT NULL | 修复后的文本 |
| `prompt_version` | TEXT NOT NULL | 使用的提示词版本 |
| `api_model` | TEXT | 使用的API模型 |
| `token_usage` | INTEGER | 消耗的token数量 |
| `processing_time_ms` | INTEGER | 处理时间（毫秒） |
| `created_at` | TIMESTAMP | 创建时间 |

**索引**:
- `UNIQUE(file_md5, chunk_hash)`
- `idx_chunk_repair_cache_file_md5`
- `idx_chunk_repair_cache_chunk_hash`

### 2.6 retry_queue - 重试队列表

存储修复失败的块，用于Evolver自进化系统。

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `id` | INTEGER PRIMARY KEY | 自增主键 |
| `file_md5` | TEXT NOT NULL | 关联的文件 MD5 |
| `chunk_id` | INTEGER NOT NULL | 块序号 |
| `original_text` | TEXT NOT NULL | 原始文本 |
| `failure_reason` | TEXT NOT NULL | 失败原因 |
| `error_type` | TEXT NOT NULL | 错误类型 |
| `error_context` | TEXT | 错误上下文（JSON格式） |
| `prompt_version` | TEXT | 使用的提示词版本 |
| `retry_count` | INTEGER | 已重试次数 |
| `max_retries` | INTEGER | 最大重试次数 |
| `status` | TEXT | 状态：pending/processing/completed/failed |
| `created_at` | TIMESTAMP | 创建时间 |
| `updated_at` | TIMESTAMP | 更新时间 |
| `next_retry_at` | TIMESTAMP | 下次重试时间 |

**索引**:
- `idx_retry_queue_status`
- `idx_retry_queue_next_retry`

### 2.7 prompt_versions - 提示词版本表

存储多版本提示词，用于Evolver自进化优化。

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `id` | INTEGER PRIMARY KEY | 自增主键 |
| `prompt_name` | TEXT NOT NULL | 提示词名称 |
| `prompt_version` | TEXT NOT NULL | 提示词版本号 |
| `prompt_content` | TEXT NOT NULL | 提示词内容 |
| `source` | TEXT NOT NULL | 来源：file/database/evolver |
| `error_pattern` | TEXT | 触发此版本的错误模式 |
| `success_rate` | REAL | 成功率 |
| `total_uses` | INTEGER | 总使用次数 |
| `successful_uses` | INTEGER | 成功次数 |
| `created_at` | TIMESTAMP | 创建时间 |
| `updated_at` | TIMESTAMP | 更新时间 |

**索引**:
- `UNIQUE(prompt_name, prompt_version)`
- `idx_prompt_versions_name_version`


## 4. 状态机

### 4.1 文件状态

```
pending ──→ processing ──→ reviewing ──→ completed
    │             │
    │             └──→ failed ──→ pending（重试）
    │
    └──→ processing（继续处理）
```

### 4.2 审核项状态

```
pending ──→ accepted
    │
    ├──→ rejected
    │
    └──→ edited
```

## 5. 数据完整性

- `files.md5` 唯一约束，确保同一文件不重复记录
- `versions.version_md5` 唯一约束，确保版本唯一性
- `versions.parent_md5` 外键引用 `versions.version_md5`（自引用）
- `review_items.file_md5` 关联 `files.md5`
- `processing_logs.file_md5` 关联 `files.md5`
