# 冒烟测试计划

## 1. 测试概述

冒烟测试（Smoke Testing）用于验证系统核心功能是否正常工作，确保主要业务流程可以正常执行。

## 2. 测试范围

### 2.1 测试环境要求

| 项目 | 要求 |
|------|------|
| 服务地址 | http://localhost:8080 |
| 数据库 | SQLite（自动创建于 data/cleaning.db） |
| 测试文件 | testing/smoking_testing/test_data/sample.txt |

### 2.2 前置条件

- 服务已启动（执行 `go run ./cmd/txtclean/` 或 `./txtclean`）
- data 目录存在（如不存在会自动创建）
- .env 配置文件已配置（如需 API 修复则需配置 LLM_API_KEY）

## 6. 故障处理

| 故障现象 | 可能原因 | 处理方式 |
|----------|----------|----------|
| 服务无法访问 | 服务未启动 | 启动服务: go run ./cmd/txtclean/ |
| 上传失败 | 文件大小超限 | 检查 MAX_FILE_SIZE 配置 |
| 处理卡住 | 服务重启导致goroutine丢失 | 点击"继续处理"按钮 |
| API返回错误 | 数据库损坏 | 删除 data/cleaning.db 重启服务 |
