1. 背景与目标

1.1 背景

VoidText 作为中文小说 TXT 清洗工具，用户在处理完成后需要在审核界面逐行审查修改建议。当前审核界面仅有单一的深色主题（寂灭风），长时间使用容易造成视觉疲劳，且缺乏个性化调节能力。

1.2 目标

为审核界面（文件查看/审查）增加类似小说网页阅读器的皮肤系统，内置多套护眼主题，同时提供用户自定义主题、字体选择、阅读间距调节等能力，提升长时间审核的视觉舒适度。

3. 内置主题设计

3.1 CSS 变量体系

每个主题定义以下 8 个 CSS 变量，覆盖审核界面的全部色彩层：

变量命名规范（kebab-case）
  • --bg-primary — 主背景色（页面最底层）
  • --bg-secondary — 次要背景色（工具栏/面板区域）
  • --bg-card — 卡片底色（浮动面板/模态框内部）
  • --border-color — 边框/分割线色
  • --text-primary — 主文字色（正文核心文字）
  • --text-secondary — 次要文字色（行号、辅助信息）
  • --text-muted — 弱化文字色（占位符、禁用状态）
  • --accent — 强调/高亮色（按钮、链接、活跃状态）

3.3 主题切换机制

CSS 属性选择器切换

在 <html> 元素上设置 data-theme="主题名"，CSS 通过属性选择器自动匹配对应的变量集合。

示例：

/* theme.css */
:root, [data-theme="dark"] { --bg-primary: #0a0a0f; /* ... */ }
[data-theme="paper"] { --bg-primary: #f5f0e8; /* ... */ }
[data-theme="green"] { --bg-primary: #c7edcc; /* ... */ }
[data-theme="night-blue"] { --bg-primary: #0d1b2a; /* ... */ }
[data-theme="warm"] { --bg-primary: #faf0e0; /* ... */ }

/* 自定义主题通过 data-theme="custom-{name}" + 行内 CSS 变量 */
[data-theme^="custom-"] { /* 由 JS 设置具体值 */ }

4.3 交互细节

  1. 色块指示器：每个颜色项左侧的色块背景色随用户输入即时变化
  2. 自动补全：输入 fff 自动补全为 #fff，或自动补全为完整 6 位 hex
  3. 格式校验：仅允许 0-9a-fA-F 字符，无效值时输入框边框变红并显示提示
  4. 实时预览：右侧预览区即时反映当前输入的配色，展示主体/次要/弱化/高亮四个层级
  5. 保存与关闭：点击"保存并应用"后将主题写入 localStorage 并关闭编辑器

4.4 自定义主题管理

  • 用户可创建 多个 自定义主题
  • 自定义主题在主题选择区以独立按钮展示，与内置主题并列
  • 每个自定义主题按钮旁有 ✕ 删除按钮（删除前二次确认）
  • 删除后若当前正在使用该主题，自动回退到默认主题（寂灭黑）
  • 自定义主题支持重命名（点击名称后进入编辑状态）

5.4 字体加载方式

CSS @font-face 声明（theme.css）
@font-face {
  font-family: 'LXGW WenKai';
  src: url('/static/fonts/lxgwwenkai/lxgw-wenkai-regular.woff2') format('woff2');
  font-weight: normal;
  font-style: normal;
  font-display: swap;
}

5.5 自定义字体（F-05）

  • 用户输入字体 URL（必须为 woff2 格式）
  • 使用 new FontFace() API 动态加载并注册到 document.fonts
  • 加载成功后自动加入字体选择下拉列表
  • 加载失败时显示错误提示，不影响现有字体选择
  • 支持删除已添加的自定义字体条目
  • 自定义字体 URL 列表存储于 localStorage（key: voidtext-custom-font-urls）

6. 阅读间距调节

6.1 调节参数

参数CSS 属性滑块范围步长默认值显示单位
字间距letter-spacing0 ~ 0.3em0.02em0em
行间距line-height1.4 ~ 2.80.11.8—
段间距p + p { margin-top }0.2em ~ 3.0em0.2em1.0emem

6.2 实现方式

通过 CSS 变量 + JavaScript 实时控制：

/* 在 style.css 中 */
.review-line-content {
  letter-spacing: var(--reader-letter-spacing, 0);
  line-height: var(--reader-line-height, 1.8);
}
.reader-paragraph + .reader-paragraph {
  margin-top: var(--reader-paragraph-gap, 1em);
}

6.3 交互细节

  • 使用 <input type="range"> 滑块控件
  • 滑块右侧同步显示当前数值（带单位）
  • 拖动滑块时通过 style.setProperty() 即时更新 CSS 变量，实时生效
  • 松开滑块后自动保存到 localStorage

voidtext-custom-theme-listJSON array自定义主题名称列表（如 ["我的主题","阅读舒适"]）
voidtext-custom-theme-{name}JSON object单个自定义主题的变量集合 + 元数据
voidtext-font-familystring当前字体名（如 默认无衬线、霞鹜文楷）

voidtext-reader-line-heightstring行间距值（如 "1.8"）

8.2 生效时机

  • 页面加载时：从 localStorage 读取全部设置并应用
  • 变更时：每次设置变更即时写入 localStorage
  • 重置时：清除所有 voidtext-* 键，回退到初始状态

9. 恢复默认设置

功能说明
  • 阅读设置面板底部提供 "恢复默认设置" 按钮
  • 点击后弹出二次确认对话框
  • 确认后清除所有 voidtext-* 相关的 localStorage 记录（不含其他应用数据）
  • 自动回退到：默认主题（寂灭黑）+ 默认字体（默认无衬线）+ 默认间距（字间距 0、行间距 1.8、段间距 1.0em）

13. 注意事项

  1. 字体许可证：霞鹜文楷为 SIL Open Font License 1.1，可在项目中免费分发和使用
  2. CSS 变量兼容性：目标浏览器均支持 CSS 自定义属性，无需 polyfill
  3. 性能：阅读设置面板采用 CSS 变量更新，不会触发重排，性能开销可忽略
  4. 无障碍：颜色输入框应提供 label 关联，颜色变更时不影响语义结构
  5. 字体文件大小：霞鹜文楷 woff2 约 2MB，首次加载后浏览器会缓存，建议在加载时显示加载状态
  6. 冲突处理：voidtext-* 的 localStorage key 应避免与项目中其他模块冲突
  7. 自定义主题名称：不允许与内置主题同名，不允许为空，长度限制 20 字符
