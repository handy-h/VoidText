审核页面 UI 设计规范

版本: v2.0 | 更新日期: 2026-05-15 | 状态: 实施中

1. 整体布局

全屏沉浸式 Diff 视图
  • 审核页面采用全屏布局，移除侧边栏
  • 顶部工具栏：审核进度、分页控件、筛选器、字体缩放、批量操作、快捷键提示
  • 中间内容区：逐行显示全文内容，审核项以 Diff 方式高亮
  • 底部操作栏：完成审核按钮、返回列表按钮

2. 行类型与样式

2.1 普通行（无审核项）

样式
  • 背景：透明
  • 文字颜色：var(--text-secondary)
  • 左侧：行号 gutter
  • 右侧：无操作按钮

2.2 原文行（有审核项）

底色分层（关键）
  • 整行浅红色底色：rgba(255, 107, 107, 0.15)
  • 被修改文字深红色底色：rgba(255, 80, 80, 0.6)，带删除线
  • 左侧边框：3px 实线，颜色 rgba(255, 107, 107, 0.6)

2.3 建议行（每个审核项一行）

底色分层（关键）
  • 整行浅绿色底色：rgba(80, 200, 120, 0.15)
  • 建议文字深绿色底色：rgba(60, 180, 80, 0.6)，无删除线
  • 左侧边框：3px 实线，颜色 rgba(80, 200, 120, 0.6)
  • 左侧 gutter 显示 → 箭头

2.4 布局示意

15 在我们生存的这个星球上，并存着无数个世界。有人类世界，有植物世界 [保留] [撤销] → 在我们生存的这个星球上，存在多个 世界。有人类世界，有植物世界 16 有空气世界，有水的世界… 17 我们的这个主人公，属于尘埃世界。

3. 逐字符对齐 Diff

核心规则
  1. 字符位置对齐：原文行与建议行的每个字符位置必须逐字符对齐
  2. 双向空格填充：
    • 建议比原文短 → 建议行填充空格
    • 原文比建议短 → 原文行填充空格
  3. 空格只用于展示：实际保存时不包含填充空格
  4. 不可见字符可视化：\n 显示为 ↵，\t 显示为 →

4. 浮动操作框

定位与显示
  • 位置：定位在原文行的右侧（position: absolute; right: 8px; top: 50%; transform: translateY(-50%)）
  • 触发条件：hover 或 active（选中）原文行时显示
  • 按钮：[保留]（Enter）/ [撤销]（Esc）
  • 多个审核项：显示 [全部保留] / [全部撤销]
  • 不遮挡文本：工具栏只在原文行上显示，不覆盖建议行

5. 快捷键

按键功能
↑ / P上一个审核行
↓ / N下一个审核行
Enter保留当前行所有审核项
Esc撤销当前行所有审核项
PageUp / PageDown翻页
Home / End首页 / 末页
Ctrl + / Ctrl -放大 / 缩小字体

6. 分页

  • 默认 50 行/页，可选 25 / 50 / 75 / 100
  • 分页基于全文行数，审核项所在的行会显示原文行 + 建议行

7. 批量审核

检测规则
  • 当多个审核项的 original 和 suggested 完全相同时，归为一组
  • 组内有 2 项以上时，显示"批量 (N)"按钮
  • 点击进入独立全屏页面，可逐项审核或全部通过/拒绝
