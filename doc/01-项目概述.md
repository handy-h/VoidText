# 项目概述

## 1. 项目背景

小说文本智能清洗工具（Novel Text Cleaner）是一个用于清洗小说 TXT 文档的桌面工具，解决错别字、乱码、广告内容、重复或缺失片段等问题。

### 1.1 核心目标

- **文件生命周期追踪**：通过 MD5 唯一标识文件，追踪从上传到完成的完整生命周期
- **处理进度恢复**：支持中断后继续处理，不丢失已有进度
- **多版本管理**：维护原始文件与中间版本的父子关系，任何版本可追溯
- **自定义规则**：每个文件可独立配置处理规则
- **本地化存储**：SQLite 数据库，数据完全存储于本地

### 1.2 使用场景

- 单人使用，无需考虑多用户协作
- 文件存储于本地，支持离线工作
- 所有文本处理均在本地完成（LLM 修复可通过 API 调用外部模型）

## 2. 功能特性

### 2.1 核心功能

| 功能 | 说明 |
|------|------|
| 文件上传与识别 | 自动解析文件名提取作者和标题，MD5 唯一标识 |
| 五步处理流水线 | 基础清洗 → 向量检测 → LLM修复 → 人工审核 → 生成文件 |
| 进度恢复 | 支持两种方式恢复：直接上传文件或从列表选择 |
| 版本链管理 | 维护原始文件与中间版本的父子关系 |
| 人工审核 | 逐条审核修改建议，支持通过/拒绝/编辑/恢复/批量操作 |
| 自定义规则 | 每个文件可独立配置规则 |
| 处理报告 | 生成包含审核统计、版本历史、处理日志的完整报告 |

### 2.2 处理阶段

| 阶段 | 说明 |
|------|------|
| 基础文本清洗 | 编码检测与转换（GBK/UTF-8）、广告移除、特殊字符处理、繁体转简体 |
| 向量检测去重 | 基于向量相似度的重复段落检测与移除 |
| LLM修复 | 调用外部 LLM 纠正错别字和语法错误，支持本地字典兜底 |
| 人工审核 | 生成待审核列表，用户逐条确认或修改 |
| 生成最终文件 | 输出清洗后的 TXT 文件 |

### 2.3 自进化监控系统

基于外部 [Evolver 项目](https://github.com/EvoMap/evolver)（Node.js GEP协议）实现智能提示词优化：

| 监控指标 | 阈值 | 触发动作 |
|----------|------|----------|
| 缓存命中率 | < 30% | 调用 Evolver 优化提示词 |
| API错误率 | > 20% | 调用 Evolver 调整提示词或重试策略 |
| 连续失败次数 | > 3 | 触发自动修复流程 |

**工作原理**：
1. 定期检查数据库中的缓存命中率和错误率
2. 当指标超过阈值时，调用外部 Evolver CLI
3. Evolver 扫描 `memory/` 目录中的错误日志（GEP协议格式）
4. 生成优化后的提示词并应用到系统中
5. 支持基于规则的回退策略，保证系统可靠性

## 5. 关键技术实现

### 5.1 文件标识

使用 MD5 作为文件的唯一标识符：
- 上传文件时计算 MD5
- MD5 匹配用于识别相同文件
- 版本链通过 MD5 追溯父子关系

### 5.2 编码处理

- 自动检测 GBK 编码并转换为 UTF-8
- 处理 HTML 实体（如 `&nbsp;`、`&amp;`）
- 混合编码时的回退处理

### 5.3 向量相似度

基于余弦相似度检测语义重复段落：
- 段落分割后生成向量
- 两两比较计算余弦相似度
- 超过阈值（默认 0.95）的段落标记为重复

### 5.4 LLM 修复

- 支持外部 API 调用（如阿里云 DashScope、DeepSeek）
- API 不可用时回退到本地错别字字典
- 按段落逐个修复，记录修改历史

### 5.5 异步处理

- 处理请求立即返回，后台异步执行
- 通过轮询 `/api/files/:md5/status` 获取进度
- 服务重启后可从中断步骤继续
