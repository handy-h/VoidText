## 性能瓶颈分析

### 🔴 主要瓶颈：Ollama Embedding 生成

**问题：**
- Ollama embedding 每批次（50 个段落）耗时 **68-163 秒**
- 平均 **121 秒/批次**，即 **2.4 秒/段落**
- 这是 **CPU 推理**的性能瓶颈，不是我们优化的相似度计算部分

**证据：**
```
2026/05/31 11:17:18 ollama_embedding_success duration=69766 text_count=50
```
- 单次 API 调用就花费 69.8 秒
- 这是 Ollama 模型推理时间，不是我们的代码

### ✅ 相似度计算优化已生效

**我们的优化针对的是：**
- 向量生成**之后**的相似度比较阶段
- 从 O(n²) 降低到 O(n × windowSize)
- 预计算模长、并行计算

**但是：**
- 当前使用 `VECTOR_MODEL_TYPE=ollama` 模式
- **95%+ 的时间花在 Ollama embedding 生成上**
- 相似度计算只占总时间的 **<5%**

### 📊 时间分配估算

对于 9,615 个段落：

| 阶段 | 耗时 | 占比 |
|------|------|------|
| Ollama embedding 生成 | 6-7 小时 | 95-98% |
| 相似度计算（优化后） | 5-10 分钟 | 2-5% |
| 其他处理 | <1 分钟 | <1% |

## 优化建议

### 🚀 立即可行的优化

#### 1. 切换到 Local 模式（推荐）⭐⭐⭐⭐⭐

**修改 `.env` 配置：**
```bash
# 从 ollama 切换到 local
VECTOR_MODEL_TYPE=local
```

**效果：**
- Embedding 生成：**瞬间完成**（本地 32 维特征计算）
- 相似度计算：**2-4 秒**（优化后的并行计算）
- **总耗时：从 6-7 小时 → 5-10 秒**（提速 **2000-5000 倍**）

**权衡：**
- ✅ 速度极快
- ✅ 无需网络/GPU
- ⚠️ 检测精度略低于深度学习模型（但对于重复段落检测已足够）

#### 2. 使用 GPU 加速 Ollama（如果有 GPU）⭐⭐⭐⭐

**前提：** 有 NVIDIA GPU 或 Apple Silicon (M1/M2/M3)

**效果：**
- Embedding 生成：**10-30 倍加速**
- 总耗时：从 6-7 小时 → **20-40 分钟**

**操作：**
```bash
# 确认 Ollama 使用 GPU
ollama ps
# 应该显示 GPU 使用情况
```

#### 3. 增大批次大小⭐⭐⭐

**修改 `vector_detector.go:135`：**
```go
const batchSize = 100  // 从 50 增加到 100
```

**效果：**
- 减少 API 调用次数：193 批次 → 97 批次
- 减少网络开销
- **预估提速 10-20%**

**权衡：**
- ⚠️ 单次调用耗时更长
- ⚠️ 可能超时（需要调整 `LOCAL_MODEL_TIMEOUT`）

#### 4. 调整相似度阈值⭐⭐

**修改 `.env` 配置：**
```bash

```

**效果：**
- 减少需要比较的段落对数
- 略微提速（但影响不大，因为瓶颈在 embedding）

## 结论

### 当前状态

✅ **相似度计算优化已成功**
- 从 O(n²) 降低到 O(n × 300)
- 预计算模长、并行计算
- 但这部分只占总时间的 <5%

❌ **真正的瓶颈是 Ollama Embedding**
- 占用 95%+ 的时间
- CPU 推理速度慢
- 每批次 50 个段落需要 68-163 秒

### 推荐方案

**对于 1MB 左右的文件：**

1. **开发/测试环境**：使用 `VECTOR_MODEL_TYPE=local`
   - 耗时：5-10 秒
   - 精度：足够检测重复段落

2. **生产环境（追求精度）**：
   - 有 GPU：使用 Ollama + GPU 加速（20-40 分钟）
   - 无 GPU：使用远程 API（如阿里云 DashScope）或 local 模式

3. **混合方案**：
   - 先用 local 模式快速去重
   - 对重要文件再用 Ollama 精确检测

### 性能对比表

| 模式 | 1MB 文件耗时 | 精度 | 成本 |
|------|-------------|------|------|
| **local** | **5-10 秒** | 中 | 免费 |
| ollama (CPU) | 6-7 小时 | 高 | 免费 |
| ollama (GPU) | 20-40 分钟 | 高 | 免费 |
| API (远程) | 2-5 分钟 | 高 | 付费 |
