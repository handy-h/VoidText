## 部署要求

- **Go 版本**：≥ 1.25.0
- **操作系统**：Linux / macOS / Windows
- **依赖**：SQLite（内置）、前端静态资源
- **可选**：Python 3（用于 Evolver 提示词优化）

## 环境配置

通过 `.env` 文件或环境变量配置：

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `PORT` | HTTP服务端口 | `8080` |
| `DATA_DIR` | 数据存储目录 | `./data` |
| `LOG_LEVEL` | 日志级别 | `info` |
| `LLM_API_URL` | LLM API地址 | - |
| `LLM_API_KEY` | LLM API密钥 | - |
| `VECTOR_API_URL` | 向量API地址 | - |
| `MAX_WORKERS` | 并发Worker数 | `4` |

## 启动方式

### 本地开发

```bash
# 使用启动脚本
./scripts/run.sh

# 或手动启动
go run cmd/voidtext/main.go
```

### 树莓派部署

使用守护进程脚本：

```bash
./scripts/raspberrypi-start.sh
```

脚本功能：
- 检查 Go 环境
- 自动构建二进制文件
- 以守护进程方式运行
- 支持开机自启配置

## 自动化部署

支持云效流水线自动部署：

1. **构建阶段**：编译 Go 二进制文件
2. **测试阶段**：执行单元测试与冒烟测试
3. **部署阶段**：上传至目标服务器
4. **验证阶段**：健康检查与回滚策略

## 监控告警

- **日志监控**：结构化 JSON 日志，支持按级别过滤
- **性能指标**：缓存命中率、API错误率、处理耗时
- **自进化监控**：Evolver 基于指标自动优化提示词
- **健康检查**：`/health` 端点返回服务状态

## 故障排除

| 现象 | 可能原因 | 解决方案 |
|------|----------|----------|
| 服务启动失败 | 端口被占用 | 修改 `PORT` 配置 |
| 数据库错误 | 数据目录权限不足 | 检查 `DATA_DIR` 权限 |
| LLM调用超时 | API地址或密钥错误 | 检查 `LLM_API_URL` 和 `LLM_API_KEY` |
| 处理进度卡住 | Worker池满载 | 调整 `MAX_WORKERS` 或检查外部API状态 |
| 内存占用高 | 大文件处理 | 调整分块大小或并发数 |

## 备份与恢复

- **数据库备份**：定期复制 `cleaning.db` 文件
- **配置备份**：保存 `.env` 文件
- **版本保留**：配置 `BACKUP_RETENTION_DAYS` 控制保留天数
