# 配置说明

## 1. 环境变量配置

通过 `.env` 文件配置，参考 `.env.template` 获取完整模板。

### 1.1 基础配置

| 变量名 | 说明 | 默认值 |
|--------|------|--------|
| `PORT` | 服务端口 | 8080 |
| `DATA_DIR` | 数据目录（含数据库） | ./data |
| `MAX_FILE_SIZE` | 最大文件大小(字节) | 104857600 (100MB) |
| `BACKUP_KEEP_DAYS` | 备份保留天数 | 7 |
| `NAME_SEPARATORS` | 文件名分隔符列表 | `-\|—\|·\|_\|` |

**说明**:
- `NAME_SEPARATORS`: 用于从文件名解析作者和标题，支持多个分隔符，按优先级排序
  - 示例: `作者 - 标题.txt` → 作者="作者", 标题="标题"
  - 示例: `作者_标题.txt` → 作者="作者", 标题="标题"

### 1.2 基础文本清洗配置

| 变量名 | 说明 | 默认值 |
|--------|------|--------|
| `ENABLE_BASIC_CLEANING` | 是否启用基础清洗 | true |
| `BASIC_CLEANING_TOOL` | 清洗工具 | regex |
| `TRADITIONAL_TO_SIMPLE` | 繁体转简体 | false |

### 1.3 向量检测配置

| 变量名 | 说明 | 默认值 |
|--------|------|--------|
| `ENABLE_VECTOR_DETECTION` | 是否启用向量检测 | true |
| `VECTOR_MODEL_NAME` | 向量模型名称 | all-MiniLM-L6-v2 |
| `VECTOR_MODEL_TYPE` | 向量模型类型 | local |
| `VECTOR_SIMILARITY_THRESHOLD` | 相似度阈值(0.0~1.0) | 0.95 |
| `VECTOR_MODEL_URL` | 向量模型API地址 | (空) |
| `VECTOR_MODEL_API_KEY` | 向量模型API密钥 | (空) |

**向量模型类型说明**:
- `local`: 使用本地简化向量计算（无需外部依赖）
- `api`: 调用外部 API 生成向量

### 1.4 LLM修复配置

| 变量名 | 说明 | 默认值 |
|--------|------|--------|
| `ENABLE_MODEL_REPAIR` | 是否启用模型修复 | true |
| `REPAIR_MODEL_NAME` | 修复模型名称 | gpt-3.5-turbo-instruct |
| `REPAIR_MODEL_TYPE` | 修复模型类型 | api |
| `LLM_API_URL` | LLM API地址 | (空) |
| `LLM_API_KEY` | LLM API密钥 | (空) |
| `COMPLETION_MODEL_NAME` | 文本生成模型名称 | gpt-3.5-turbo-instruct |
| `COMPLETION_TEMPERATURE` | 生成温度(0.0~2.0) | 0.3 |
| `COMPLETION_MAX_TOKENS` | 最大生成token数 | 2048 |

**修复模型类型说明**:
- `api`: 调用外部 LLM 进行文本修复（推荐）
- `local`: 使用本地错别字字典进行修复

### 1.5 自进化监控配置

| 变量名 | 说明 | 默认值 |
|--------|------|--------|
| `BASE_DIR` | 项目根目录（用于定位 memory/ 目录） | . |
| `ENABLE_EVOLVER` | 是否启用自进化监控 | false |

**Evolver 外部依赖**:
- **Node.js**: >= 18
- **Evolver CLI**: 通过 `npm install -g @evomap/evolver` 安装
- **Git 仓库**: 项目根目录需已初始化 git（Evolver 需要 Git 上下文）
- **Python3**: 用于运行适配器脚本 `scripts/evolver.py`

**启用步骤**:
1. 安装 Node.js 和 npm
2. 全局安装 Evolver CLI: `npm install -g @evomap/evolver`
3. 确保项目目录已初始化 Git: `git init`（如果尚未初始化）
4. 在 `.env` 中设置 `ENABLE_EVOLVER=true` 和 `BASE_DIR=/path/to/project`
5. 确保 `memory/` 目录存在（系统会自动创建）

## 2. 配置示例

### 2.1 阿里云 DashScope + qwen 模型

```env
VECTOR_MODEL_TYPE=api
VECTOR_MODEL_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
VECTOR_MODEL_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
LLM_API_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
LLM_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
COMPLETION_MODEL_NAME=qwen-max-2025-01-25
COMPLETION_TEMPERATURE=0.3
COMPLETION_MAX_TOKENS=2048
```

### 2.2 DeepSeek 模型

```env
LLM_API_URL=https://api.deepseek.com/v1
LLM_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
COMPLETION_MODEL_NAME=deepseek-chat
COMPLETION_TEMPERATURE=0.3
COMPLETION_MAX_TOKENS=2048
```

### 2.3 本地模式（无需 API）

```env
VECTOR_MODEL_TYPE=local
REPAIR_MODEL_TYPE=local
```

## 3. 兼容旧配置

以下旧配置仍然支持，会自动映射到对应的新配置：

| 旧变量名 | 映射到 |
|---------|--------|
| `EXTERNAL_API_URL` | `VECTOR_MODEL_URL` 和 `LLM_API_URL` |
| `EXTERNAL_API_KEY` | `VECTOR_MODEL_API_KEY` 和 `LLM_API_KEY` |
| `EMBEDDING_MODEL_NAME` | `COMPLETION_MODEL_NAME` |

## 4. 文件名解析规则

`NAME_SEPARATORS` 支持的分隔符示例：

| 分隔符 | 示例文件名 | 解析结果 |
|--------|-----------|----------|
| ` - ` | `金庸 - 天龙八部.txt` | 作者=金庸, 标题=天龙八部 |
| `—` | `金庸—天龙八部.txt` | 作者=金庸, 标题=天龙八部 |
| `·` | `金庸·天龙八部.txt` | 作者=金庸, 标题=天龙八部 |
| `_` | `金庸_天龙八部.txt` | 作者=金庸, 标题=天龙八部 |
| `~` | `肖忉~赶尸家族.txt` | 作者=肖忉, 标题=赶尸家族 |

## 5. 数据目录结构

配置 `DATA_DIR` 后，自动创建以下子目录：

```
DATA_DIR/
├── cleaning.db        # SQLite 数据库
├── uploads/           # 上传文件和中间版本
├── backups/           # 备份文件
└── reviews/           # 审核记录
```
